## 게시판 공통 규칙
1. 자기 담당 작업 외 파일을 건드리지 않는다. 공용 파일은 담당 작업이 명시한 것만.
2. 담당자는 `## 상태 보고`의 **자기 줄 한 줄**만 갱신한다: `DONE/진행/막힘 — 산출물 경로, 핵심 수치, 변경 파일`.
3. API 키·비밀은 로그·보고·커밋·이 게시판 어디에도 기록하지 않는다. 없으면 사용자에게 요청하고 멈춘다.
4. 막히면 `막힘 — 사유`를 쓰고 멈춘다. 다른 담당자 작업을 대신 하지 않는다.
